## 📌 Project Overview

This project demonstrates desktop application test automation using SikuliX and Python (Jython). It focuses on automating form-based workflows through image recognition, reusable scripts and data-driven testing concepts.

## 🎯 Project Objectives

- Automate repetitive desktop application testing workflows.
- Explore image-based element identification.
- Implement data-driven test execution.
- Improve test execution consistency and evidence collection.

## 🛠️ Technologies Used

- SikuliX IDE
- Python (Jython)
- Oracle Forms (demonstration context)
- Oracle SQL
- CSV Test Data

## ✨ Key Features

- Image-based desktop automation.
- CSV-based data-driven testing.
- Reusable automation functions.
- Synchronization and wait handling.
- Exception handling.
- Execution logging and screenshot evidence.

## 🧪 Testing Approach

- Functional Testing
- Positive and Negative Testing
- Data-Driven Testing
- UI Validation
- Test Execution and Evidence Collection
